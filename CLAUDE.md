# Web design workflow

## Skills
- **design-taste-frontend**: use for overall direction and layout.
- **impeccable**: use for design rules and brand consistency. Run `/impeccable init` once per project before the first design task.
- **emil-design-eng**: use as a final pass on motion and interactions.

## Figma
- When I share a Figma link, use the `figma` MCP server to read it.

## Visual QA
- After building any page, use the `playwright` MCP server to open it at desktop and mobile widths, take screenshots, and fix any visual problems.
