# Sterling Growth Systems website

Homepage for Sterling Growth Systems: custom websites with an AI assistant built in.

The live design is a claude.ai Design canvas: https://claude.ai/artifact/F9EXD1Dv7PaBuJPs618BWK

## Contents

- `site/Main.dc.html`: the homepage artboard (Design Component format: `<x-dc>` markup plus a `DCLogic` class). Images are referenced as `/_blob/<id>` uploads on the canvas.
- `site/canvas.json`: the canvas index (artboard size and layout).
- `site/assets/`: the five sample photographs used in the before/after and sample-site mockups.
- `PRODUCT.md`: product context (audience, pricing, evidence on hand) used by the impeccable skill.
- `CLAUDE.md`: the web design workflow rules for Claude Code.
- `.claude/skills/`: the installed design skills (design-taste-frontend, impeccable, emil-design-eng), pinned in `skills-lock.json`.
- `.taste-skill/direction.json`: the dealt art direction.
